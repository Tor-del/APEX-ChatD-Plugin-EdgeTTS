The package includes the [LGPL](licenses/edge-tts-LICENSE.txt), [GPL](licenses/GPL-3.0.txt),
and source for the separate library and its `ScreenReader.Speech` dependency.
Run `dotnet build ScreenReader.Edge` from the packaged `source` directory to rebuild it.
